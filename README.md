# Student Record Manager (Console)
A simple menu-driven C# console application to manage student records. It allows users to add, view, search, and delete student information with automatic age calculation and text file storage.

## Features

- **Add Student:** Store Roll Number, Name, Date of Birth, and Marks.
- **View Students:** Display all saved student records.
- **Search Student:** Find students by name using string functions.
- **Delete Student:** Remove student records using Roll Number.
- **Age Calculation:** Automatically calculate student age using DateTime.
- **File Handling:** Save records to a text file and load them when the application starts.
- **Data Storage:** Uses List<Student> to manage student records.

## Technologies Used

- C#
- .NET
- Object-Oriented Programming (OOP)
- List Collection
- DateTime
- File Handling
- String Functions
